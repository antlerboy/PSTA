# Commissioning Compass and practice resources

The PSTA website provides the March 2026 Commissioning Compass assessment, the sixteen-question smartCompass reflection, and the June 2026 v2 beta matrix. Each edition identifies its source and version. Source questions, factors, score bands, and the original AI prompt retain their wording.

The workspaces support separate perspectives, evidence, actions, review dates, device saving, editable JSON, readable notes, and print/PDF. Answers are not submitted to the PSTA or an AI service. Saving on a device is optional. Input pages do not load analytics or third-party scripts.

The AI download combines the original prompt and the current answers. The user checks the file and runs it in an authorised AI account. The website does not generate AI analysis or send email.

The reading pages use teaching text from the June 2025 template and the eight approach sections from the June 2023 adult social care pre-reading. Source dates, references, and acknowledgements are retained. One source diagram retains its visible credit. The 2017 asset-based commissioning article retains its original publication date and text.

The case-clinic resources provide a host guide, participant brief, and case record. Enquiry preparation opens a draft in the visitor’s email app and never sends it automatically.

RedQuadrant owns the shared Leading Transformation record. The PSTA publishes a checked copy, with modules, fees, support, and accreditation drawn from it. The build checks the curriculum against the shared record.

Run `npm run test:compass`, `npm run check:programme`, and `npm run build` for source, record, programme, and site checks. The browser checks cover saving, record portability, reviews, downloads, privacy on input pages, and mobile layout.
